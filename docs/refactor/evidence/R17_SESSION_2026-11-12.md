# R17 iOS remote client

Tauri iOS dùng SPA và SDK chung, IPC JSON/base64 và Rust HTTP transport với
TLS của hệ điều hành. Host mở ở màn hình kết nối server. Credential lưu trong
Keychain theo origin chuẩn hóa, dùng service riêng của ứng dụng và tắt
đồng bộ iCloud. Tài liệu cấu hình bảo mật tham chiếu [Apple Keychain item accessibility](https://developer.apple.com/documentation/security/restricting-keychain-item-accessibility).

## Kiểm trên Xcode Simulator

Trên macOS có Xcode, chạy `npm ci`, `npm exec -- tauri ios init --ci` và
`npm exec -- tauri ios dev` trong thư mục `ui`. Chọn simulator và dùng hai
server fixture với origin khác nhau. Dùng token thử riêng cho từng origin.
Hook iOS đợi SPA build xong trước khi mở simulator. Fixture iOS còn kiểm IPC
trên WebView chỉ có `crypto.getRandomValues`; UUID v4 vẫn lấy entropy từ Web Crypto.

- Mở app lần đầu và kết nối server A. Enroll, đóng app, mở lại và xác nhận
  phiên đã enroll còn hoạt động. Chuyển sang B và kiểm A không gửi token sang B.
- Upload tệp nhỏ từ Files. Mở bàn phím ở Chat, xoay màn hình và kiểm composer
  cùng nút Stop vẫn truy cập được.
- Đưa app vào nền hoặc ngắt mạng sau khi server ghi nhận request. Khi quay lại
  xác nhận app tiếp tục đúng request và cursor, với đúng một admission POST.
- Stop request đang chạy và đọc trạng thái `cancelled` trên server. Logout A,
  khởi động lại và xác nhận A phải enroll lại, còn B vẫn truy cập được.

Dependency graph và type check riêng module Keychain pass trên Windows với
target `aarch64-apple-ios-sim`. Bộ UI có 124 test pass, gồm fixture IPC cho
iOS và Android. Biên dịch toàn app và chạy Tauri/WKWebView cần macOS/Xcode. Simulator gate R28 và signing
gate R29 còn mở.
