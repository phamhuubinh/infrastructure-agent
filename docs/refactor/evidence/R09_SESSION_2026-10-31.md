## Current implementation

- Explicit default-off SSH target config and pinned host-key options; no workstation
  credential discovery, model connection material or local script execution.
- Bundled fixed helper source travels on stdin. The isolated -I/-S fixture confirms
  its modules need no remote Orion/Pydantic/psutil installation. The first fixture
  attempted a full payload argv and hit Windows206; it was corrected to stdin,
  which is the actual production transport contract.
- Actual remote sh/bash discovery, bounded four-command/sixteen-handle lifecycle,
  incremental raw-byte cursor output, concurrent draining and omission accounting.
  Incomplete process observations retain unknown handles rather than evicting them.
- A Linux new-session supervisor installs parent-death signaling with parent
  recheck, independently enforces timeout, emits bounded observed shell metadata
  and kills its own group. Helper separately verifies groups/observed descendants;
  pidfd signaling avoids killing reused observed PIDs. Missing pidfd/proc access
  cannot become a verified termination report. Unknown handles get another bounded
  cleanup attempt on explicit cancel/shutdown.
- Private no-follow cache provenance includes UID, boot and process start ticks;
  cleanup deletes only known source/marker files and never recurses/kills stale PIDs.
- Nonblocking helper stdin/stdout, heartbeat lease, closed RPCs, no stderr retention,
  bounded client closure and no channel restart/replay. Local client closure never
  proves remote termination.
- Bootstrap exposes canonical commands for configured SSH even with paired endpoints
  disabled, and appends only opaque target references to model context. Capability
  preparation precedes new command dispatch; existing original calls are checked
  before preparation and never reconnect. Server handle commits before user run.
- Stop during preparation creates no command handle/launch. Existing scope/hash/modes,
  transient evidence and exact confirmation remain the shared R08 runtime path.
- Context preserves ssh: namespace and omits global targets in Device Chat. Legacy
  Linux operations also respect Device Chat exact target binding. Numeric /proc
  identity parsing accepts Unicode/parentheses in comm without hiding identity.

## Detached-process regression and containment repair

An added actual Linux double-fork/setsid fixture reproduced a false successful
cleanup: the daemon survived while `process_tree_terminated=true`. Earlier five
process fixtures did not cover this. The supervisor now becomes a per-command
Linux child subreaper before launching a shell, kills/reaps adopted children using
pidfds and requires kernel `waitpid` ECHILD before reporting private cleanup
completion. The helper also independently checks observed group/child identities.
Missing/invalid/incomplete private cleanup metadata prevents a verified termination
claim, including a later cancel retry. The helper sends TERM to the supervisor
first so it can reap detached children; bounded fallback cannot invent proof.

[Subreaper evidence](R09_QEMU_SUBREAPER_2026-10-31.json) retains the original failed
daemon assertion, an intermediate six-pass run, a nine-pass/one fixture-race run,
and the final **10/10 actual Linux tests** with11 matching current SSH/test hashes.
The race was `pid_exists` followed by a fresh Process lookup after the child had
already disappeared; an identity-checked Process object and NoSuchProcess handling
now observe that valid cleanup without weakening the live-process assertion.
The final suite checks detached descendants on normal exit, timeout, cancel, EOF
and abrupt helper death. [Updated actual SSH smoke](R09_QEMU_SSH_SUBREAPER_2026-10-31.json)
also passes3/3 with the new helper payload digest. No fake stdio or Windows-only
test is counted as this actual Linux evidence.
