# R14 và phần kiểm tra wheel của R18

R14 hoàn tất trong phạm vi source, recipe và fixture. Checkout bắt đầu ở
`5b66a98646ec8c9a854e61ffafe67c938b0731b2`. Điểm vào Linux và cách cài/cập nhật/gỡ
theo [HEADLESS.md](../../operations/HEADLESS.md).

- `orion serve` dùng chung ASGI app, chạy foreground với một worker và loopback
  mặc định. Có thể chạy khi thiếu UI bundle. Unit systemd user dùng prefix cài đặt
  hiện hành và chờ shutdown có giới hạn.
- `chat` và `run` gửi đúng một prompt UTF-8 qua API admission hiện có. JSON lines
  phản ánh từng event đã lưu. Chế độ văn bản chỉ in câu trả lời đã chốt. Cursor
  nối lại quan sát. SIGINT khi gửi hoặc chờ dùng API hủy theo cùng session, UUID
  và prompt. Gián đoạn khi dùng `request watch` chỉ ngắt quan sát.
- Các lệnh quản trị đi qua owner API. Quyết định duyệt command dùng hash payload
  chính xác. CLI hỗ trợ phiên owner cookie qua HTTPS, phiên native qua mã
  enrollment và bearer ngắn hạn cấp từ ngoài. Hai phiên tương tác giữ credential
  trong bộ nhớ và gọi endpoint thu hồi khi kết thúc. Transport từ chối redirect
  và giữ origin cố định.
- R18 đã có CI smoke cài backend wheel vào venv riêng trên Linux, dùng HTTP
  provider fixture cục bộ, kiểm tra không có UI/display, SIGINT và dữ liệu sau
  restart. Release smoke dùng cùng bài kiểm tra với CLI từ archive đã cài.
  CI và release validation kiểm tra drift OpenAPI và SDK. Các phần còn lại của R18 gồm
  toolchain/dependency locks, automation đa nền tảng và vòng đời release artifacts.
- R18 bỏ `ui/bun.lock` và `ui/bunfig.toml` sau khi kiểm tra các entrypoint UI,
  installer và CI. Chúng dùng npm và `ui/package-lock.json`. Hai record audit
  giữ lại lý do xóa và đường thay thế.

## Kiểm chứng

- 11 test CLI pass trên Windows, gồm lost-response retry qua owner API, cursor,
  hủy trước admission, remote owner auth/thu hồi và origin validation.
- Sau khi bỏ Bun, `npm ci --ignore-scripts` cài 469 package từ lock trong bản sao
  sạch. 81 file UI còn lại trong bản sao khớp byte với checkout. 115 test UI,
  TypeScript, ESLint và production bundle/package assertions đều pass.
- Build wheel `orion-0.1.3-py3-none-any.whl`, SHA-256
  `e7570b7db5da8f393e6e399b177c3c33cd5732324b1883a29de55bfc7a9ea859`.
  Cài wheel vào thư mục riêng trên Windows, chạy process `serve` với UI directory
  trống và provider loopback thật. `chat`, `doctor` và sáu lệnh liệt kê tài nguyên
  trả kết quả hợp lệ. Process của phép kiểm này được dừng từ harness.
- Ruff, format, mypy toàn backend (146 module), mypy Linux cho hai module CLI,
  architecture, drift OpenAPI/SDK và whitespace pass. `operations_check.py`
  gọi trực tiếp POSIX script nên dừng trên Windows với WinError 193.
- Lượt backend đầu không đặt `PYTHONUTF8=1` có 1.609 pass, 8 fail, 17 skip và
  23 subtests pass. Sáu lỗi thuộc các bài kiểm POSIX đã ghi ở R13. Hai lỗi còn lại
  là worker Unicode trên `cmd` và PowerShell với stdout Python CP1252. Hai test đó
  pass khi chạy lại với cấu hình UTF-8 của R13. Toàn bộ backend với cấu hình đó
  có **1.611 pass, 6 fail POSIX đã biết, 17 skip, 23 subtests pass**. Lượt chạy
  gồm toàn bộ suite. Audit tools có 13 test pass, ledger giữ 598 file hiện hành
  và 19 record đã xóa/di chuyển.
- Ubuntu 24.04.5 x86_64 guest, Python 3.12.3. QEMU fixture boot thành công với
  single-thread TCG và `icount shift=1` sau lỗi IO-APIC/timer ở cấu hình thường.
  SHA-256 wheel khớp với bản build, cài vào venv mới, `pip check` pass. Smoke trên
  wheel đã cài xác nhận headless startup, chat qua HTTP provider fixture, SIGINT
  thoát 130 và request đạt `cancelled`, rồi kiểm tra session còn sau restart.
- Trên cùng guest, dùng unit systemd user với prefix venv thử nghiệm và thư mục
  dữ liệu riêng. `doctor` trả JSON, unit báo `active`, dừng với `Result=success`
  và exit status 0. Gỡ runtime link sau kiểm tra. Venv không có fastembed hoặc
  onnxruntime, guest không có Node trong PATH.
- R26 vẫn cần kiểm chứng archive phát hành và worker lifecycle. Windows wheel
  smoke, Linux installed-wheel smoke, ASGI auth fixture và CI definition có
  phạm vi bằng chứng riêng. Các gate native còn lại, mobile, signing và
  live-provider vẫn mở.
