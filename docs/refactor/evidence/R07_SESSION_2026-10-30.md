# R07 checkpoint — 2026-10-30

R07 remains in progress. This checkpoint covers restart ownership and interrupted
request recovery; it is not data lifecycle or whole-refactor acceptance.

## Semantic findings and implementation

- `bootstrap.build_application` previously expired only pending authorizations;
  ordinary queued/running requests survived process restart and could be replayed.
  It now acquires an OS-backed exclusive runtime lease before schema work and
  recovers all interrupted requests and scheduled runs in one SQLite transaction.
- `SQLiteStore` now compares request state before starting/completing work, records
  one terminal failure and notice for each interrupted request, expires pending
  authorizations, and rolls all recovery changes back together if event writing
  fails. Committed tool results distinguish known outcomes from unconfirmed tool
  calls. No model or tool is invoked by recovery.
- `ChatRuntime.run` rejects duplicate invocations of the same queued request.
  A rejected duplicate cannot overwrite the active request's terminal state.
- The lease is released on normal close, failed composition, abrupt process exit,
  and garbage collection. The lock inode is retained to avoid unlink races.
- Scheduler and authorization tests were updated to assert the new composition-root
  recovery contract. Standalone scheduler reconciliation remains tested.
- Legacy document owner migration now takes a SQLite online snapshot in a newly
  created private directory/file before table replacement. The replacement runs
  inside `BEGIN IMMEDIATE` with foreign-key validation and rollback on failure.
  A Windows ACL readback checks that the backup directory and file have protected
  DACLs with only the current user and LocalSystem grants. The snapshot is kept
  for recovery; it is a **database-only pre-migration backup**, not a complete
  data export (blobs and protected credential records are not included).
- Knowledge document listing, status, read and delete now check the supplied
  principal/workspace/Project/endpoint scope against the stored session identity
  before returning session or Project sources.
