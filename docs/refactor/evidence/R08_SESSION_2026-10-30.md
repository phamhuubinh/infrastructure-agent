## Implementation and reviewed boundaries

- Canonical system.command.run/status/cancel use the shared registry/runtime.
  Server SQLite scope-owned handles are committed before dispatch; original
  request/call dedup never relaunches a command. Only identity, normalized input
  hash and safe observed metadata persist. Script/cwd/output remain transient.
- Worker command capability defaults off, independently of server modes and file
  roots. Portable startup explicitly asks for account-rights shell permission.
  Generic endpoint tools/API cannot bypass CommandService ownership. Actual shell
  discovery includes OS fallbacks for frozen empty-PATH execution.
- Worker output drains concurrently after the combined raw-byte cap; separate
  UTF-8/replacement streams use bounded raw-byte cursor pages. Malformed identity,
  shell, cursor, payload bounds or unverified cancellation cannot become evidence.
- Windows commands launch suspended, enter a no-breakaway kill-on-close Job Object
  before resume, and use Job active accounting for verified tree cleanup. Native
  source tests cover failed assignment, timeout, cancel, close and abrupt worker
  exit with real descendants. These are not packaged executable tests.
- POSIX uses a new group/session and observed child creation identities. Linux
  static typing is checked; native process behavior still needs R26.
- Private per-account temporary script cache establishes/readbacks ACLs before
  bytes, durably records provenance and prunes only proven dead/reused-owner PID
  artifacts on the next initialization. Unknown files, live records, links and
  altered provenance are preserved; there is no recursive command-file deletion.
  A crash may leave a private script until the next cache initialization.
- PowerShell uses -File semantics; native child exit propagation requires explicit
  `exit $LASTEXITCODE`. Long scripts, quotes, pipes, Unicode, separate streams,
  cwd with spaces, output pressure and raw cursor split/replacement have fixtures.
- Stop/failure cancels owned original-request commands without a second approval.
  Concurrent cancellation shares one in-flight attempt. The runtime Stop fixture
  exposed a simultaneous stream-end exception overriding cancellation: draining
  now consumes that exception after interruption wins. Ordinary errors still
  propagate normally; mutation drain keeps its established uncertainty contract.
- Same-connection status reconciles a lost ACK without run replay. Connection
  replacement/restart retains unknown state and unavailable output; request and
  command recovery share one transaction. Manager wire validation and the generic
  command bypass denial are exercised with the actual Executor protocol.
- Current-request arguments/results use timeline-identity transient overlays;
  canonical SQL/events/diagnostics omit payloads and terminal cleanup clears caches.
- Owner-authenticated no-store live approval payload shows exact escaped script
  and effective settings in shared Chat/Project/Device UI. Allow binds the pending
  hash; unauthenticated, wrong session, blind/wrong-hash and stale allows fail.
