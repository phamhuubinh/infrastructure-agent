# R03 implementation checkpoint

R03 remains in progress. Native DeepSeek/Claude/OpenAI adapters and full provider
conformance are not implemented by this checkpoint.

Implemented:

- Immutable provider registry, keyed by explicit provider/protocol and stable
  adapter identity. Option schemas are validated and deeply snapshotted. Missing
  adapters/options/capabilities, mismatched settings/profile and foreign adapter
  continuation fail before transport. There is no alternate model/vendor fallback.
- Default bootstrap uses the registry around the existing compatible adapter.
  Injected fake backends retain their previous test seam. The compatible adapter
  also rejects direct native-profile misuse, protecting callers such as legacy
  benchmark paths from silently sending native requests as Chat Completions.
- ModelSettings no longer restricts provider_type to a single regex value; it
  accepts a typed ModelProfile. The legacy HTTP model configuration DTO still
  needs migration to typed profiles and remains explicitly tracked below.
- CredentialResolver port and explicit env:NAME resolver. No vendor key guessing,
  enumeration, logging or model-facing key storage. References resolve once when
  binding a profile; malformed/missing/control-character/oversize secrets return
  category-only errors. Settings keep the resolved credential private.
- SQLite adds nullable profile_json without deleting or rewriting legacy rows.
  New typed configurations store credential references and NULL api_key; IDs bind
  their serialized profiles. Existing plain configuration updates cannot partially
  overwrite typed profiles. Existing legacy plaintext credentials are preserved,
  not falsely claimed migrated to a protected secret store.
- Shared application ModelConfigurationService reads the active row/profile in
  one SQL snapshot and binds it before entering the runtime loop. ChatRuntime
  receives a settings-provider callable, keeping registry/vendor composition out
  of the loop. Typed/legacy profiles share the existing single active selection.

provider IDs now cover the three native vendors plus the explicit compatible
path, with no single-provider API regex. A native request requires its complete
typed profile, a registered adapter and supported options. Missing keys/adapters
cannot change active selection. Typed updates are atomic and cannot erase an
unmigrated legacy secret. HTTP validation returns type/location/message without
echoing request input/context that can contain provider credentials. Public profile

retry counts are explicitly rejected as unsupported until safe retry conformance
is implemented; no retry or mutation replay is silently introduced.

## Protocol foundation continuation, 2026-10-30

Implemented bounded decoded-byte transport (256 KiB line/event, 8 MiB stream),
strict UTF-8, multiline SSE framing and unfinished-frame rejection. JSON rejects
ambiguous duplicate object fields and nonfinite numbers, including exponent
overflow. Compatible completion rejects filtered/truncated/unknown stop reasons,
bounded tool-call accumulation and content emitted after completion. Existing
response doubles now emit byte-encoded complete frames; their semantic assertions
are retained. Native tool-name projection is deterministic/legal/reversible and
rejects names outside the advertised registry; native adapters must use it.

Provider errors explicitly attest retry safety. Only connection establishment
errors/timeouts qualify, with a profile maximum of two retries; no fallback or
whole-runtime replay. Every received normalized event, including a secret-prefix
delta withheld from public output, prevents replay. Cancellation is checked
between attempts. The real HTTPX MockTransport + ChatRuntime + AUTO mutation test
executes its fixture handler exactly once when the post-tool model connection is
retried; uncertain ReadError fails without retry. No OS mutation is performed.
HTTPX exception definitions checked against https://www.python-httpx.org/exceptions/.

A request-local secret context protects resolved stored keys in events/history/
logs/diagnostics; literal streaming redaction buffers possible key prefixes across
delta boundaries. Credential-bearing model tool arguments fail before dispatch.
The request context resets on completion. Registry continuation envelopes are
integrity-checked with an instance-private MAC and bound to request identity,
profile/model/endpoint/options, credential fingerprint and full RuntimeScope.
Only the adapter receives its exact original private payload. Cross-scope/key/
request/profile/integrity/restart failures are explicit safe errors. Envelopes
are private protocol values, not resumable persistence or reasoning disclosure.
