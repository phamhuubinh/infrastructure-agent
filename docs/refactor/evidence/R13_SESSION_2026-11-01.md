Graph/source caller checks preceded retirement. Git retains the original tracked
versions; the audit ledger retains removal records and final dispositions.

All compatibility apiFetch paths resolve through generated operation descriptors;
new chat/command/settings/profile/resource code uses typed SDK operations. Cookie
browser and native host/vault modes remain separate. Server profiles persist only
id/name/origin; secrets/history/command handles are not in profile storage. Browser
server changes navigate to the target origin; native switches abort old observers,
dispose their retry generation and reject stale responses even if a bridge ignores
abort. Native actual OS bridge/vault implementations remain R15–R17.

Chat and Device Chat admit by an immutable UUID/content/session intent and observe
the same request by GET. Cursor recovery and durable event pages never resubmit a
known request. Ambiguous admission retains the original nonce for explicit recovery;
another intent cannot silently replace it. Pending transient intent state clears
on server/auth changes. Stop reserves a cancelled admission nonce when the original
request response is lost: a later admission cannot start the model/tool loop.
For an active request Stop waits for canonical terminal status, rather than
equating an HTTP acknowledgment with process cleanup. Actual backend fixtures cover
both cancellation-before-admission and cancellation of a live waiting runtime.

Added Commands observation/cancel UI; Settings server profiles, typed vendor
profiles/credential references, configuration doctor, MCP owner controls, product
skill install/preferences/remove, native enrollment/session revoke and read_only
scheduler jobs. Mobile bottom navigation and dynamic viewport height complement
the desktop sidebar. No direct HTTP shell-run bypass was added: command creation
uses the canonical authorized Chat/Device Chat tool path.
