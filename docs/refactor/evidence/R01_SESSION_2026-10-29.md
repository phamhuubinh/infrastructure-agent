## Phát hiện cần triển khai sau audit

- ModelSettings chỉ chấp nhận openai_compatible; composition luôn khởi tạo
  OpenAICompatibleBackend; ModelTurn/ContextMessage chưa có adapter-owned opaque
  continuation envelope. Chưa có ba adapter native bắt buộc.
- ToolDefinition.provider_schema gắn với Chat Completions; projection bỏ một số
  constraints như string length. Cần projection riêng theo capability/protocol,
  canonical validation vẫn bắt buộc ở server.
- Bootstrap/integrations/mutation authorization còn Grafana/Zabbix/fixed Linux
  family. Đã xác định callers, chưa xóa mixed module chứa SSH.
- Endpoint protocol chỉ có fixed operations/process aliases, chưa có command
  handles/run/status/cancel. Device binding trong ToolRunner hiện áp riêng prefix
  endpoint.*, chưa thể dùng nguyên trạng cho system.command.*.
- Đã đọc thêm worker policy/executor/channel/CLI/portable: file roots chỉ giới hạn
  file helper, không thể dùng làm shell sandbox; executor còn cấm shell theo tên
  executable. Cleanup chỉ terminate/kill các direct child, chưa có process-tree
  command lifecycle. Channel chống replay trong connection, nhưng command handles
  và restart reconciliation vẫn cần contract mới. Temporary/remembered state có
  đường riêng hiện hữu, chưa chạy native smoke để chứng minh lease/exit cleanup.
- CLI vẫn yêu cầu packaged UI trước khi serve, không có headless chat/run/stdin/
  JSON/profile/skill/MCP/command administration đầy đủ.
- Bundled skill guidance phù hợp yêu cầu, nhưng chưa có runtime loader/capability
  catalog; tuyệt đối không gọi package Markdown là loader đã chạy.
- UI root còn gọi window.__lovableEvents qua module vendor; bun.lock/bunfig còn
  vendor packages; Vite dùng TanStack Start/server entry. Đã đọc root/middleware/
  error paths; chưa xóa hoặc claim static/native build.
- LocalAccessAdapter chỉ có một principal local; security redaction dựa env và
  một số patterns, không chứng minh secret-store/opaque-state isolation đầy đủ.
- Paths dùng Linux data layout cả trên Windows; worker/backend version trùng
  giá trị nhưng đang khai báo hai nơi. Cần migration/version source khi đóng gói.
- RequestBudget cleanup được đọc; nhánh deadline trước khi tạo task cần xem lại
  việc close coroutine đầu vào, và cancellation-resistant dispatch cần kiểm thử
  process lifecycle trước khi tái sử dụng cho commands.
