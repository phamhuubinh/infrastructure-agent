# R18 automation và vòng đời artifact

Baseline Git `5b66a98646ec8c9a854e61ffafe67c938b0731b2` với các thay đổi R14/R18
trong working tree. Các archive kiểm thử local ghi `source_dirty: true`.

## Triển khai

- `scripts/refactor/dev.py` cung cấp doctor, bootstrap, check, build, package và
  lock cho Windows/Linux. CI đọc cùng version files. Lock Python 3.12 chia theo
  core, development, worker và portable. `pip` kiểm hash trước cài, wheel và
  editable dùng bộ build tool đã lock. UI dùng `npm ci`.
- Release archive chứa lock runtime và digest. Installer mặc định trên Python
  3.12 dùng lock, rồi cài chính xác wheel. Luồng optional semantic và Python mới
  hơn dùng dependency metadata. Gỡ server/worker xóa phần cài đặt được nhận diện
  và kiểm tra đường dẫn, giữ dữ liệu riêng.
- Server/worker archive stage trong thư mục tạm riêng và ghi metadata nén cố định.
  Builder mặc định yêu cầu Git sạch. Portable build dùng venv mới và từ chối
  combine nếu record dirty, khác source hoặc khác platform dự kiến.
- Linux operations check đối chiếu CLI hiện tại, cô lập cấu hình Orion và fail
  nếu cổng test không khả dụng. Windows CI dùng bộ native regression riêng,
  còn bộ POSIX installer chạy trên Linux.

## Phạm vi còn mở

R18 còn matrix artifact của R15–R17. Desktop capture/input có gate riêng.
R25–R29 và live provider giữ scope riêng. Các workflow mới
được xác thực YAML cục bộ. Chưa có chạy hosted hoặc publication trong lượt này.

## Job build mobile

CI có job Android trên Ubuntu 24.04 với JDK 21 và NDK 29. Job khởi tạo
project Tauri, đóng gói APK debug arm64, kiểm ZIP và native library trong APK,
rồi in SHA-256. Job iOS trên macOS 15 kiểm SDK simulator và build đích
`aarch64-sim`. Đã kiểm cấu trúc YAML và fixture hook staging Android tại máy
Windows. Hai job chờ lượt chạy hosted, và chưa có kết quả emulator, simulator
runtime hoặc signing.

Windows CI dùng sidecar vừa build để tạo NSIS debug, kiểm WebView2 trên
executable đã cài và so SHA-256 database trước và sau khi gỡ. Lệnh tương
đương đã chạy với installer R16 trong môi trường Windows cục bộ. Job
hosted chờ chạy.
