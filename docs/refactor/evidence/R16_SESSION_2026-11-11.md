# R16 Android remote client

Shared Tauri bridge đọc platform do host trả về. Android fixture khởi động ở
màn hình chọn server và không mở managed backend. UI dùng safe area và file input
hiện có. Khi app native mobile vào nền hoặc mất mạng, Chat tạm dừng quan sát
request đã được server nhận. Khi quay lại và có mạng, Chat đọc tiếp cùng request
và cursor. Admission chưa xác minh vẫn giữ nonce để người dùng xử lý rõ ràng.

124 UI test pass, gồm hai fixture IPC cho mỗi nền tảng mobile. Fixture thực hiện mất mạng giữa lúc đọc stream, xác nhận client
mở lại cùng request khi online, chỉ gửi một POST admission và không gọi Stop.
Fixture IPC Android kiểm body UTF-8 qua JSON/base64 và bearer theo đúng origin.
TypeScript, ESLint, production bundle và packaged UI assertions pass. Bản
Windows build lại với UI dùng chung cũng qua smoke WebView2, chat/Stop và remote
enrollment/logout.

Đã triển khai `OrionCredentialVault` bằng khóa AES-GCM trong Android Keystore.
Credential được tách theo canonical origin, mã hóa với origin làm AAD và ghi
atomically trong no-backup directory. Hai file Java compile với Java 17, Android API jar Robolectric và stub chữ ký
IPC đối chiếu Tauri 2.12.5. Kiểm tra canonical origin chạy qua trên JVM. Rust đã đăng ký plugin Android và nối ba lệnh vault với Java. Android dùng
cùng transport có kiểm origin, với TLS qua Rustls và bộ CA Mozilla. Tauri
dùng cấu hình Android riêng cho IPC JSON/base64. Cấu hình Windows giữ NSIS và
managed backend. Android Keystore trên thiết bị, file picker, bàn phím và
foreground native vẫn chờ kiểm chứng.

Temurin JDK 21.0.13+9 đã tải và kiểm SHA-256 theo Adoptium, chạy được trong
thư mục toolchain riêng. `tauri android init --ci --skip-targets-install` xác
nhận máy hiện thiếu Android SDK/NDK. R27 chưa có APK hoặc emulator smoke.

## Chuẩn bị project Android

Từ thư mục `ui`, sau khi có Android SDK/NDK, CMake và JDK, chạy
`npm ci`, `npm exec -- tauri android init --ci` rồi
`npm exec -- tauri android build --debug --apk`. Hook Android chép hai file Java
từ source được quản lý vào project đã sinh, rồi build SPA trước khi Gradle chạy.
`npm exec -- tauri android dev` dùng cùng hook và đợi SPA sẵn sàng.
