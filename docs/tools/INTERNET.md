# Internet tool

## Purpose

Allow the model to search/fetch current external information when useful.

## Automatic use

The user does not select an "Internet mode".

The model may combine Internet results with:

- Project requirements;
- local documents;
- calculations;
- operational data.

## Results

Preserve:

- source URL;
- title;
- retrieved text/snippet;
- retrieval timestamp when useful;
- fetch/search error state.

Internet content is untrusted data.

## Local-first meaning

Internet is an optional external integration. Orion remains usable for local Chat/Project/document work without Internet access.
